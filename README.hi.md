# NewsNest

**50 शब्दों या उससे कम में ख़बरें।**

NewsNest छोटी ख़बरों का ऐप है। हर ख़बर एक कार्ड है, जिसमें एक हेडलाइन, ज़्यादा से ज़्यादा 50 शब्दों का सारांश और पूरी ख़बर का लिंक होता है। आप फ़ीचर्ड कैरोसेल और ट्रेंडिंग लिस्ट देख सकते हैं, कैटेगरी के हिसाब से ख़बरें खोज सकते हैं, सर्च कर सकते हैं, ख़बरें बाद में पढ़ने के लिए सेव कर सकते हैं, या अपनी ख़ुद की ख़बर लिख सकते हैं।

यह MERN स्टैक (MongoDB, Express, React, Node) से बना है। डिफ़ॉल्ट रूप से यह **बिना किसी डेटाबेस या लॉगिन के** चलता है, इसलिए आप सिर्फ़ दो कमांड में इसे चला सकते हैं।

> **Hack Day प्रोजेक्ट।** यह रिपॉज़िटरी जान-बूझकर अधूरी रखी गई है: कुछ चीज़ें टूटी हुई हैं और कुछ फ़ीचर मौजूद नहीं हैं। हर एक के लिए एक GitHub issue है। कोई एक issue चुनें, उसे ठीक करें और pull request खोलें। देखें [CONTRIBUTING.md](CONTRIBUTING.md)।

## फ़ीचर

- ब्रेकिंग न्यूज़ टिकर और फ़ीचर्ड ख़बरों का कैरोसेल
- ट्रेंडिंग लिस्ट, कैटेगरी फ़िल्टर और "Load more" के साथ ताज़ा ख़बरों का ग्रिड
- कैटेगरी पेज, Top News रैंकिंग और संबंधित ख़बरों वाले स्टोरी पेज
- कैटेगरी और सॉर्ट फ़िल्टर के साथ सर्च
- ख़बरें बाद में पढ़ने के लिए सेव करें (आपके ब्राउज़र में सेव होती हैं)
- अपनी ख़बर लिखें, लाइव शब्द-गिनती और प्रीव्यू के साथ
- शेयर बटन, डार्क मोड और हर स्क्रीन साइज़ पर ठीक दिखने वाला लेआउट

## इसे चलाएँ

आपको **Node.js 18.11 या उससे नया वर्ज़न** चाहिए।

```bash
npm install
npm run dev
```

फिर **http://localhost:5173** खोलें। API http://localhost:5000 पर चलता है।

बस इतना ही। किसी डेटाबेस, लॉगिन, API key या Docker की ज़रूरत नहीं है।

### वैकल्पिक सेटिंग्स

इनमें से कोई भी सेटिंग बदलने के लिए `server/.env.example` को `server/.env` में कॉपी करें:

| वेरिएबल | डिफ़ॉल्ट | यह क्या करता है |
| --- | --- | --- |
| `PORT` | `5000` | API का पोर्ट |
| `MONGO_URI` | खाली | इसे खाली छोड़ें तो NewsNest कभी किसी डेटाबेस से नहीं जुड़ता: ख़बरें मेमोरी में रहती हैं और सर्वर रीस्टार्ट होने पर रीसेट हो जाती हैं। इसे तभी सेट करें जब आप ख़बरें MongoDB में सेव करना चाहते हों। |
| `API_DELAY_MS` | `700` | धीमे नेटवर्क की नक़ल करने के लिए हर API कॉल में ज़्यादा से ज़्यादा इतने मिलीसेकंड की रैंडम देरी जोड़ता है। इसे बंद करने के लिए `0` सेट करें। |
